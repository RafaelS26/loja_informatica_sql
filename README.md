Loja de Informática - Consultas e Visualizações SQL
​Este repositório contém o desenvolvimento de um banco de dados para uma Loja de Informática, focando na criação de consultas de validação e visualizações (Views) para facilitar a análise de dados de clientes e vendas.
​🚀 Tecnologias Utilizadas

​SQL Server / MySQL (ou o SGBD que você estiver usando)
​DML/DDL para estruturação e consultas

​📂 Estrutura do Repositório
​O projeto está organizado da seguinte forma:
​quereis/: Contém scripts de validação para garantir a integridade dos dados.
​select_validação.sql: Consultas para conferência de registros.

​vistas/ (ou Views): Scripts para criação de visualizações estratégicas.

​cliente_gasto_total.sql: Calcula o montante total investido por cada cliente.

​cliente_pedido_total.sql: Consolida a quantidade de pedidos realizados.

​cliente_simples.sql: Uma visão simplificada com os dados básicos dos clientes.
